# موقع Healthy - فرع العريش (شمال سيناء)

موقع ويب متجاوب لمتجر منتجات الألبان **Healthy - فرع العريش** مبني باستخدام HTML5 و CSS3 و Vanilla JavaScript بدون أي مكتبات خارجية.

## هيكل الملفات
- `index.html`: الهيكل الدلالي الرئيسي، الهيدر، شريط البحث، وشريط التنقل السفلي.
- `css/style.css`: الهوية البصرية (الأزرق الملكي `#0D4EDB` والأصفر الليموني `#E3EA3E`) وخط `Qatar2022`.
- `js/data.js`: بيانات المنتجات والأقسام (الألبان، المشروبات، الزبادي، الجبن، العروض) وإعدادات فرع العريش.
- `js/app.js`: خوارزمية التنقل بين الصفحات، البحث الفوري، إدارة السلة عبر `localStorage`، وإرسال الطلبات عبر واتساب.

## تخصيص رقم الواتساب
افتح ملف `js/data.js` وعدّل قيمة `whatsappNumber` برقم هاتف الفرع بصيغة دولية (مثل `2010xxxxxxxx`).
